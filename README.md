# Koto · 日語文法筆記本

日語文法規則筆記本：**API 文法盤點**為主；**動詞形態分析**（一段・五段・サ変・カ変）作參考。  
規則可選 **三格**變化指示；查詢歷史與待辦存在本機。

## 功能

| 功能 | 說明 |
|------|------|
| 查詢模式 | API 文法／API 單字（需 Key）；全關為手動模式，可選字套用 |
| 本地辭典 | 常用繁中（`data/ja-zh-lite.json`）＋本機單字庫。開著時 API 文法可不列單字，缺口可手動／API 單字補 |
| 詞彙原形 | 先辭典／詞庫，不夠再打 API；動詞標一段／五段／サ変／カ変，形容詞標い／な |
| 專案 | 歌詞／對話等連貫文本；句子依序編號永久保存（不寫一般歷史） |
| 動詞分析 | kuromoji + 啟發式：原形、類型、活用、分項步驟（參考） |
| 規則 CRUD | 新增／編輯／刪除；可選三格 |
| 缺失→待辦 | 單筆或全部加入；**建卡儲存後自動清除**對應待辦 |
| 盤點→筆記本 | 「查看規則」跳轉規則列表並定位高亮 |
| 查詢歷史 | 自動記錄；再看一次／刪除／清空；可搜尋 |
| 三格配色 | 設定頁可選主題 |
| AI 自動填寫 | 依規則名補齊說明／三格 |
| 匯入／匯出 | JSON 備份（規則 + 專案） |

## 規則卡片欄位

```text
id, title, category, explanation,
requiresConjugation, conjugation{ ichidan, godan, sahen },
created_at, updated_at
```

- **requiresConjugation**：是否需要動詞依類型變化  
- **conjugation**：一段／五段／サ変 簡短規則（不要舉例）  
- 已取消 `keywords` 本地關鍵字欄位與本地規則掃描查詢  

## 查詢流程

1. API 文法／單字需已設定 API Key；全關為手動模式，仍可查詢並選字套用  
2. 輸入單詞或整句 → 依開啟模式盤點  
3. 與筆記本比對 → **已收錄**／**尚未收錄**  
4. 缺失可加入待辦或建立規則；儲存後清待辦  
5. 附帶動詞形態分析（參考）  

## 快速開始

kuromoji 字典需 HTTP 載入，**請勿 file:// 開啟**。

```bash
cd "日語文法筆記本"
npx --yes serve .
```

或執行 `開啟Koto.bat`。

## 資料存放

- localStorage 鍵名 `jgn_*`（歷史 `jgn_history_v1`；專案 `jgn_projects_v1`）  
- 首次載入 `data/seed-rules.json`  
- 本地辭典：`data/ja-zh-lite.json`（常用繁中）＋本機單字庫  
- 設定匯出為 `{ type, rules, projects }`；相容舊版純規則陣列  

## 設計原則

1. 查詢以 **API 盤點** 為準  
2. 動詞分析與三格服務學習，不替代 API 盤點  
3. 待辦與建卡聯動；歷史僅本機  

> API Key 只存在瀏覽器 localStorage。
